앱처럼 설치하기

회원가입 없이, 지금 쓰던 기록 그대로 홈 화면에 아이콘으로 설치할 수 있어요.

📱 아이폰 (Safari 필수)

인스타그램·카카오톡 안의 인앱 브라우저나 크롬에서는 설치 메뉴가 뜨지 않아요. 반드시 Safari 앱으로 열어주세요.

  1. Safari로 사이트 접속홈 화면의 파란색 나침반 모양 Safari 앱을 열고 사이트 주소를 입력하세요.
  2. 공유 버튼 누르기화면 아래쪽(최신 기종은 위쪽)에 있는, 네모 상자 위로 화살표가 나오는 모양의 공유 아이콘을 누르세요.
  3. '홈 화면에 추가' 찾기메뉴를 위로 쓸어올려 아래로 내리면 '홈 화면에 추가' 항목이 있어요. 안 보이면 맨 아래 '동작 편집'에서 추가할 수 있어요.
  4. 이름 확인하고 추가이름과 아이콘 미리보기가 뜨면 그대로 두고 오른쪽 위 '추가'를 누르세요.
  5. 아이콘으로 실행 확인홈 화면에 생긴 아이콘을 눌러 주소창 없이 전체화면으로 열리는지 확인하세요.

🤖 안드로이드 (Chrome)

아이폰보다 훨씬 간단해요. 크롬이 알아서 설치 버튼을 보여줘요.

  1. Chrome 앱으로 사이트 접속파란색 동그라미 모양 Chrome 앱을 열고 사이트 주소를 입력하세요.
  2. 점 3개 메뉴 누르기화면 오른쪽 위, 세로로 놓인 점 3개(⋮)를 누르세요.
  3. '홈 화면에 추가' 또는 '앱 설치' 누르기기종에 따라 문구가 조금 다를 수 있어요.
  4. 이름 확인하고 추가'추가' 또는 '설치' 버튼을 누르면 홈 화면에 아이콘이 자동으로 생겨요.
  5. 아이콘으로 실행 확인홈 화면 아이콘을 눌러 앱처럼 전체화면으로 열리는지 확인하세요.

💻 맥북 (Safari, macOS Sonoma 14 이상)

2023년 이후 나온 macOS(Sonoma 14 이상)라면 사파리에서 바로 "웹 앱"으로 저장할 수 있어요. 그보다 오래된 macOS는 아래 "그 외 방법"을 참고하세요.

  1. Safari로 사이트 접속맥북의 Safari 앱을 열고 사이트 주소를 입력하세요.
  2. 메뉴 막대에서 '파일' 클릭화면 맨 위 메뉴 막대의 '파일'을 누르고 'Dock에 추가'를 선택하세요. (또는 주소창 옆 공유 버튼 → 'Dock에 추가')
  3. 이름 확인하고 추가웹 앱 이름을 확인하고 '추가'를 누르세요.
  4. Dock에서 실행 확인화면 하단 Dock에 아이콘이 생겨요. 눌러보면 주소창 없는 간소화된 창으로 독립적으로 실행돼요.
macOS의 "웹 앱"은 사파리와는 별도로 동작해서, 방문 기록이나 저장된 데이터가 사파리 창에서 볼 때와 분리될 수 있어요. 설치 직후엔 기존 기록이 안 보일 수 있으니, 그런 경우 사파리에서 직접 접속해 확인해보세요.

그 외 방법 (Sonoma 이전 macOS, 또는 Chrome 사용 시)
Chrome이면 오른쪽 위 점 3개 메뉴 → '도구 더보기' → '바로가기 만들기'를 누르면 비슷하게 독립 창으로 쓸 수 있어요. 구형 Safari라면 주소창의 사이트 아이콘을 데스크탑이나 Dock으로 직접 드래그해서 바로가기를 만들 수도 있어요.

알아두면 좋은 것

회원가입 없음 이 사이트는 로그인이나 회원가입 없이 작동해요. 브라우저(또는 설치된 앱)에 데이터가 저장되기 때문에, 같은 기기·같은 브라우저로 접속했을 때만 기존 기록이 이어져요.

웹 = 앱 홈 화면 아이콘은 새로운 앱이 아니라 지금 보시는 이 웹사이트를 여는 지름길이에요. 그래서 브라우저로 볼 때와 아이콘으로 열 때 기록이 자동으로 똑같이 보여요. 별도 동기화가 필요 없어요.

아이폰의 홈 화면 아이콘, 맥의 Dock 웹 앱은 iOS/macOS 특성상 일반 브라우저 창과 저장 공간이 분리될 수 있어요. 설치 직후 기존 기록이 안 보이면, 원래 쓰던 Safari 창에서 다시 확인해보세요. 안드로이드 Chrome은 대부분 같은 저장 공간을 공유해서 이런 문제가 거의 없어요.
